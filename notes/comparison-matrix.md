# 14.10 evidence and compatibility matrix

Status is assessed for **this public 26.06-14.10.00 package and the reviewed source snapshots**, not for every private research build or later commit.

| Subject | Confirmed fact | Third-party claim | Untested hypothesis / 14.10 limit |
|---|---|---|---|
| Release identity | [Sony lists 26.06-14.10.00](https://www.playstation.com/en-gb/support/hardware/ps5/system-software-info/); the downloaded file's SHA-256 is recorded in [provenance](provenance.md). | — | No live console version was read. The downloaded update need not match the console's installed firmware. |
| Outer `SLB2` | Our local parser validates one entry at byte `1024`, length `1,261,406,781`, against the original file's bounds. | [Historical PS4 parser](https://github.com/nikosradio/ps4tools/blob/2aabe4da09ba14c41f3a0d8516aa756742ef4688/pupunpack.c) documents a similar wrapper layout. | Other SLB2 variants may differ; our parser deliberately rejects layouts it cannot bound within the first 512-byte table block. |
| Inner PUP | The first four inner bytes are `54 14 F5 EE`; the 256-window byte-statistics result is in [experiment notes](experiments.md). | [PS5 PUP unpacker](https://github.com/zecoxao/ps5-pup-unpacker/blob/005cccc908142c35ab7280e7f9eef8d5203c21e0/PUP.cpp) recognizes that magic but says its input must already be decrypted. | The inner directory, files, code, and cryptographic state remain unverified. High entropy alone cannot classify encryption versus compression. |
| WebKit / PSFree | The reviewed [source](https://github.com/kmeps4/PSFree/blob/368d82aa40d3017c220757ce315761adb5f06678/psfree.mjs) labels its PS5 range `[1.00, 6.00)`. | Project associates the chain with CVE-2022-22620. | No evidence from this repository that 14.10 is vulnerable or that the same browser component is present. |
| WebKit / FontFace | The reviewed [historical writeup and code](https://github.com/ChendoChap/PS5-Webkit-Execution/blob/ad157f5c074818658ca842301837fab43e08dc00/.github/README.md) focus on PS5 4.03. | Authors associate their browser issue with CVE-2021-30889. | It provides no version-specific evidence for the WebKit build or bug status on 14.10. |
| UMTX | [FreeBSD advisory](https://www.freebsd.org/security/advisories/FreeBSD-SA-24:14.umtx.asc) confirms CVE-2024-43102 in supported FreeBSD branches. | [PS5Dev README](https://github.com/PS5Dev/PS5-UMTX-Jailbreak/blob/2cf6778ebe89ff35255e1c228826d0d2155e9d2a/README.md) claims PS5 vulnerability through 7.61 and integrated support through 5.50. | The PS5 14.10 kernel patch state cannot be inferred from either source. No 14.10 test occurred. |
| Relapse | Reviewed [ntfargo browser gate](https://github.com/ntfargo/Relapse-Exploit/blob/dd8e4e0914c5e9d066ee1f9b056be76cb992c8e0/src/firmware.js) ends at 13.60 and would reject 14.10; [soniciso1 README](https://github.com/soniciso1/relapse/blob/112dbe5949e9c3de923bb0909289c58a9c082151/README.md) also ends at 13.60. | Both projects claim an exploit chain for subsets of 7.00–13.60. | Lack of 14.10 in an allowlist does not prove the underlying bugs are fixed. It does mean these snapshots offer no documented 14.10 support. |
| PS5SDK | [PS5Dev README](https://github.com/PS5Dev/PS5SDK/blob/a2e03a2a0231a3a3397fa6cd087a01ca6d04f273/README.md) lists firmware-dependent kernel offsets only through 4.51. | [Modern payload SDK](https://github.com/ps5-payload-dev/sdk/blob/f5d40f02770e9b0001dd9e18056eca70b3da8b40/README.md) targets already exploited PS5s. | Neither SDK by itself parses or decrypts 14.10, and no 14.10 loader was established. |
| Mitigations | Sony only says 14.10 includes unspecified security fixes. | [Historical 4.03-focused writeup](https://github.com/ChendoChap/PS5-Webkit-Execution/blob/ad157f5c074818658ca842301837fab43e08dc00/.github/README.md) describes SMEP, SMAP, XOM, Clang CFI, and the hypervisor. | Which mitigations changed in 14.10 is unknown without version-specific trusted binaries or measurements. |

**Meaning of the columns:** "confirmed" is an observation on the local artifact, source code itself, or a primary advisory about its own product. "Third-party claim" records what a project author says about PS5 behavior. "Untested" names what this lab has not established. A project's own compatibility statement is not an independent 14.10 test.
